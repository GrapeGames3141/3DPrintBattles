# PrintForge Summon Lab 0.1.1

Godot 4.7.1 Windows-first prototype with an arm64 Android demo build.

## Changes from 0.1.0

- Added a Model dropdown to the main control panel.
- Added the initial model entry: `Ironbound Goblin Warrior`.
- Retained the selected first flat rank-shield treatment at the front edge of the base.
- Preserved rarity, strength, animation, summon, touch rotation, and rigid character-shield behavior.
