# Armored creature concepts

## Cinderpaw Full Suit v1

`cinderpaw_full_suit_concept_v1.png` is a non-runtime visual target for showing
equipped armor directly on a living creature. It preserves Cinderpaw's face,
ears, quadruped proportions, paws, filament texture, and flame-tail silhouette
while adapting the catalog Full Suit into modular creature armor.

The concept uses dark printed plates, worn brass edges, and restrained cyan
seams so armor remains readable against Cinderpaw's orange body at mobile size.
The intended production approach is an armor overlay or authored armored sprite
variant; this image does not replace the existing living sprite sheet.

Generated with the built-in image-generation tool in `stylized-concept` mode,
using the existing Cinderpaw sheet and Full Suit raw print
print as identity and design references.
