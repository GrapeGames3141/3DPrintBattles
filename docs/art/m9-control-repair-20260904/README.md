# M9 shared-control crop repair

Existing binding/wide-tab crops contain large blank margins and neighboring
fragments. This offsets native labels and makes small controls unreadable.

[Clean text-free hardware source](clean-hardware-atlas-source-v1.png) is a controlled
ImageGen correction of the approved brass/leather/parchment family. It is source art,
not a runtime atlas. Each of the six isolated components needs an individually
measured content rectangle, actual-alpha calibration, reviewed compact insets,
and correct nine-slice/content margins. The output does not follow equal cells
exactly; blind grid slicing would repeat the original defect.

Names, arrows, labels, selection, focus, disabled reasons and feedback remain native.
Focus uses a transparent edge/glaze; it must never cover text with another bitmap.
The lever is not a text container. Runtime promotion belongs to Terra after read-only
UI approval and root review. Provenance records the literal prompt and references.
