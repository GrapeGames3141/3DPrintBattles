# PrintForge — living-creature battle concepts

**CONCEPT REVIEW ONLY. This folder is not an APK or a playable update.**

Open `review-index.html` after downloading the folder, or browse the individual
PNGs in `captures/r7/` directly on Google Drive. Each of 15 states has original
941x1672 and phone-size 576x1024 / 720x1280 versions.

The new ImageGen floor removes the six card-like platforms. The creatures, raw
prints, blueprints, card backs and physical controls reuse existing PrintForge art.
This is 2.5D staging of animated sprites, not a claim of new mesh-based 3D creatures.
The proposed sequence is visible layers -> raw completion -> awakening -> launch
and landing -> living battlefield creature -> attack contact. Cards remain in hand.

The HTML and PNGs are offline composition concepts, not Godot captures. Their sample
values do not prove implemented gameplay. The generated floor is text-free; all
dynamic text and controls must remain native when implemented.

The gameplay changes are already approved: 200 base printer HP, +50 Chassis and
normal damage; automatic deployment; public cycle forecast; fitting equipment after
printing; owned-card deck assistance; guided first bot battle. This review asks only
for approval of the new battle-art supplement before runtime integration.

The last delivered APK remains `0.8.9-ui-alignment`, version code 105. This concept
delivery does not replace it and does not contain any of the new runtime fixes.
After art approval, implementation, runtime/visual review and Android verification,
a separately versioned APK and README will be delivered without overwriting it.

DriveFS copies are verified by byte size and SHA-256. Cloud-visible synchronization
must be reported separately and is not established by a matching local DriveFS file.
