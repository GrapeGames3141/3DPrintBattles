## Cinderpaw v1 provenance and limitation

Generated by built-in ImageGen from the existing
`assets/creatures/2d/blueprints/v2/cinderpaw_blueprint_ink_v2.png` and
`assets/creatures/2d/raw/cinderpaw_raw_print.png`. The original approved side
blueprint remains silhouette authority. Front/top width and hidden anatomy in this
study are **inferred**, not measured facts from the original references.

Brief: one existing Cinderpaw, three separated intact side/front/top orthographic
views, oversized feline head, triangular ears, central flame tuft, closed friendly
eyes, stout horizontal torso, four short grounded animal legs, rounded paws, one
connected scalloped flame tail. Uniform orange clay/filament, plain ivory studio
background, no labels, dimensions, UI, armor, detached parts, or pedestal.

The generated side image retains some three-quarter perspective and must not replace
the approved side reference or be treated as calibrated orthographic evidence.
Review/approval and matched-camera geometry evidence are still pending. An actual
model requires full-volume geometry, editable rebuild controls, source `.blend`,
`.glb` export, bounds and mesh metrics, attachment anchors, and visual fit review.

The required tool-managed C: generation was copied here to durable E: storage and
verified by byte size and SHA-256 before handoff.
