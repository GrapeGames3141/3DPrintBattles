# PrintForge Combat POC 0.3.4

This build adds touch camera controls to combat. One-finger horizontal drag rotates the battlefield, two-finger pinch zooms, and drag gestures are separated from taps so camera movement cannot accidentally issue a grid command.

## Builds

- `PrintForge-Combat-POC-0.3.4-arm64.apk` — Android arm64, package `com.tak.printforge.combatpoc`, version code 8
- `PrintForge-Combat-POC-0.3.4.exe` — Windows desktop
