# Tiered Armor and Core Socket (staged design)

The equipment model has one complete **Suit** tier slot: Standard,
Reinforced, Arcane, Masterwork, or Legendary. It deliberately represents a
full suit rather than modular equipment.

Every full suit has an image-authored recessed bezel and a signature-green
source gem. A Core is optional: installing one recolors that complete gem,
while leaving the bezel and full-suit visual intact.
Cores are a separate, small set of deterministic gameplay modifiers.

The approved master is recolored by source-material signatures: blue dominance
drives suit plates and green dominance drives the complete gem. An empty socket
renders the gem smoky gray. There is no spatial gem mask or per-Core raster
variant.

- No modular equipment; every equipped loadout is one complete suit.
- Save/profile/catalog migrations are deferred until release; this staging
  prototype is intentionally data- and presentation-only.
