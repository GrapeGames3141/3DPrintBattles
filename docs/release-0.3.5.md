# PrintForge Combat POC 0.3.5

This build greatly extends combat camera zoom. Pinching now moves the camera toward the battlefield along its full viewing angle, lowers the closest distance from roughly 48 world units to under 10, and uses higher pinch sensitivity.

## Builds

- `PrintForge-Combat-POC-0.3.5-arm64.apk` — Android arm64, package `com.tak.printforge.combatpoc`, version code 9
- `PrintForge-Combat-POC-0.3.5.exe` — Windows desktop
