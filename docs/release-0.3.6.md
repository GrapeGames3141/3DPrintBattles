# PrintForge Combat POC 0.3.6

This Android arm64 build adds tactical map camera navigation while preserving tap-versus-drag protection for grid commands.

## Camera controls

- One-finger drag pans across the battlefield.
- Two-finger twist rotates the view.
- Two-finger vertical slide tilts the view.
- Pinch zooms in and out.
- Reset View restores the default tactical framing.
