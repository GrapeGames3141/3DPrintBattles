# Support-card source provenance

These five PNGs are unmodified runtime-source copies selected for the offline
support-card milestone. `resources`, `defense`, `offense`, and `utility` are 4x2
atlases mapped in catalog order; utility only consumes the first six cells. The
separate card-back sheet is used directly for hidden local-versus presentation.

## Approved generation concepts and mapping

The supplied approved ImageGen concepts are: **resources** (filament/spools and
forge planning), **defense** (patches, cooling, layers and repair), **offense**
(sparks, snare, locks and finishing tools), **utility** (switching, overclocking,
washing and reset tools), and a **neutral hidden card back**. Runtime copies are
`assets/cards/support_cards_*_source_v1.png` and
`assets/cards/support_card_back_source_v1.png`; provenance copies remain in this
directory with the same names. No prompt wording was embedded in the supplied PNG
metadata, so this ledger deliberately records the exact approved concepts rather
than inventing a prompt transcript.

- Resources cells 0–7: raw_filament, heated_spool, print_accelerant,
  emergency_coil, calibration, forge_map, print_preview, spare_nozzle.
- Defense cells 0–7: quick_patch, reinforced_layer, coolant, dense_infill,
  flux_tape, safety_brace, repair_drone, spark_guard.
- Offense cells 0–7: arcane_spark, windup, filament_snare, layer_lock,
  tempered_edge, spool_siphon, anchor_bolt, final_pass.
- Utility cells 0–5: switchback, overclock, resin_wash, hot_swap,
  thermal_paste, soft_reset. Cells 6–7 intentionally remain blank.
